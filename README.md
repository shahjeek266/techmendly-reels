# TechMendly Reels

Files for the @techmendly Instagram account.

- `reels/<id>.mp4`: finished Reels (1080x1920, H.264/AAC)
- `covers/<id>-cover.png`: cover images
- `captions/<id>.txt`: caption + hashtags
- `queue.json`: posting order; the daily 7 PM (Pakistan time) task posts the first item with status "pending", then marks it "posted".

Public URL pattern: https://raw.githubusercontent.com/shahjeek266/techmendly-reels/main/<path>
